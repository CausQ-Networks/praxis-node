# Praxis Remote Node

A remote node for Praxis to support scaling and HA. This container serves as a lightweight wrapper for the API calls made by both Badger and Gerbil into a Praxis node. Instead of communicating with a local instance of Praxis, it instead proxies those requests to a remote Praxis head server. 

Remote nodes are used with the Praxis Cloud and Praxis Enterprise.

Take a look at the [docs](https://docs.praxis.causq.com/manage/remote-node/understanding-nodes) for more information on Praxis Remote Nodes.

For the Praxis repository, see [here](https://github.com/CausQ-Networks/praxis).
